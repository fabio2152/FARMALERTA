# FARMALERTA

Aplicación web monolítica (Java 21 + Spring Boot + Thymeleaf + PostgreSQL) para farmacias y boticas que controla cada lote por fecha de vencimiento, avisa con anticipación, recomienda con IA qué hacer con lo que está por vencer e impide vender lo vencido.
